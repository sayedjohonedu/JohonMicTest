## 2026-06-05 - Adding aria labels to icon buttons\n**Learning:** This codebase relies on many SVG icon buttons without explicit text. Relying on `title` isn't enough for screen readers. Explicit `aria-label` attributes must be added to all `icon` or `icon-only` buttons across all modals and UI files.\n**Action:** Add `aria-label` describing the button's action for all SVG-only buttons across the app.
