## 2026-06-11 - Prevent RCE via unvalidated shell.openExternal
**Vulnerability:** Arbitrary window creation (`web-contents-created` without a window open handler) and `shell.openExternal` was directly exposed to renderer processes over IPC (e.g., `open-url`, `bridge-error-open-url`). This pattern could allow a malicious actor or cross-site scripting payload to trigger Remote Code Execution (RCE) by passing arbitrary `file://` or `smb://` protocols.
**Learning:** `shell.openExternal` accepts unvalidated system-level URIs directly. Electron renderer contexts should never blindly pass strings to `openExternal` without strict protocol validation. Moreover, missing `setWindowOpenHandler` allows arbitrary child window spawning which can be hijacked.
**Prevention:** Always restrict child window creation in `web-contents-created` via `contents.setWindowOpenHandler({ action: 'deny' })` and explicitly validate URL protocols (`http:`, `https:`, `mailto:`) before calling `shell.openExternal`.
