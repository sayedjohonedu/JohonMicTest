## 2024-10-18 - Clipboard Monitoring Performance Optimization
 **Learning:** Electron's `clipboard.readImage()` is extremely expensive because it extracts data from the system clipboard and instantiates a full `NativeImage` buffer. Calling this inside a tight polling loop (e.g. 500ms) will severely degrade app performance, especially with large image content. Similarly, querying massive TEXT columns blindly using `SELECT *` across hundreds of database rows leads to high memory and IPC overhead.
 **Action:** Gate `clipboard.readImage()` calls by checking `clipboard.availableFormats()` first. Use SQLite string truncation (`substr(text, 1, 3000)`) for list queries where only preview strings are required, and fetch full-length fields on-demand through dedicated IPC handlers (e.g. `cb-get-entry`).
